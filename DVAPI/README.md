# DVAPI Security Analysis

This folder documents my analysis of 10 API security challenges from [DVAPI](https://github.com/payatu/DVAPI/tree/main).

## Objective

Understand common API security vulnerabilities by examining their root causes, vulnerable code, and possible fixes.

## Documentation Format

Each challenge is documented using the following structure:

- **Challenge Idea:** A brief description of the vulnerability.
- **Root Cause:** The underlying security weakness.
- **Vulnerable Code:** The relevant code responsible for the vulnerability.
- **Fixed Code (Illustrative):** An example of a possible remediation.
- **Fix:** A summary of the recommended security measures.



*These notes are for educational purposes and are based on challenges in a deliberately vulnerable API application.*
